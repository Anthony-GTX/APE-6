## 📚 Descripción

Repositorio con las soluciones en Java de los seis ejercicios de la Actividad Práctica Experimental (APE 6), centrados en arreglos unidimensionales y su procesamiento.

## 🎯 Objetivos

- Almacenar y procesar datos mediante arreglos.
- Calcular sumas, promedios y cantidades bajo condiciones.
- Validar datos ingresados por teclado.
- Buscar elementos y determinar sus posiciones y frecuencias.
- Relacionar información mediante arreglos paralelos.
- Aplicar métodos de la clase `java.util.Arrays`.

## 🧩 Ejercicios

| N.º | Tema | Contenidos |
|:--:|---|---|
| 1 | Control de gastos semanales | Arreglo `double`, total, promedio, aumento del 10 % y recorrido inverso. |
| 2 | Producción por turno | Índices pares, condición de número impar mayor a 15 y promedio. |
| 3 | Asistencia y rendimiento | Validación de notas, promedio, aprobados, reprobados y filtro bajo el promedio. |
| 4 | Búsqueda y conteo | Frecuencia de un valor y primera posición encontrada. |
| 5 | Máximo y mínimo | Arreglos paralelos, `posMax`, `posMin` y promedio. |
| 6 | Clase Arrays | `copyOf()`, `sort()`, `toString()` y `binarySearch()`. |

## ⚙️ Requisitos

- JDK 17 o superior.
- IntelliJ IDEA, Eclipse, Visual Studio Code o cualquier editor compatible.
- Terminal o consola.

## ▶️ Compilar y ejecutar

Abre una terminal dentro de `src` y ejecuta:

```bash
javac Ejercicio01_ControlGastosSemanales.java
java Ejercicio01_ControlGastosSemanales
```

Para ejecutar otro ejercicio, reemplaza el nombre del archivo y de la clase. Ejemplo:

```bash
javac Ejercicio06_OperacionesConArrays.java
java Ejercicio06_OperacionesConArrays
```

## 🧠 Conceptos aplicados

`arrays`, `length`, ciclos `for` y `while`, condicionales `if/else`, acumuladores, contadores, validación con `Scanner`, búsqueda secuencial, arreglos paralelos y métodos de `java.util.Arrays`.
